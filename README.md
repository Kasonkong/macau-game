# 濠江飛馳 · Macau Open World

在按真實比例重建的澳門自由駕駛：開的士載客、跑跨海大橋計時賽、到 25 個地標打卡。

**▶ 點開即玩：<https://kasonkong.github.io/macau-game/>**

另有一個可以慢慢欣賞城市的 [澳門立體沙盤](https://kasonkong.github.io/macau-game/sandbox.html)，點選任何建築可查看名稱、地址和高度。

## 操作方式

開始畫面或遊戲選單（右上角 ☰）裏可以切換兩種操作方式，選擇會自動記住。電腦預設是鍵盤，手機和平板預設是屏幕按鈕。

| 動作 | 鍵盤 | 屏幕按鈕 |
| --- | --- | --- |
| 走路／駕駛 | `W` `A` `S` `D` 或方向鍵 | 左下搖桿（推到盡是跑步） |
| 上車／落車 | `F` | 「上車／落車」 |
| 跳／手掣漂移 | 空白鍵 | 「跳／手掣」 |
| 跑步 | `Shift` | 搖桿推到盡 |
| 開始或結束載客 | `T` | 「載客」 |
| 大地圖 | `M` | 「地圖」或點小地圖 |
| 響號 | `H` | 「響號」 |
| 切換鏡頭距離 | `C` | 「鏡頭」 |
| 轉動鏡頭 | 拖動滑鼠，滾輪縮放 | 拖動畫面 |
| 選單 | `Esc` | ☰ |

## 玩法

- **自由探索**：整個澳門都能步行或駕駛，包括四條澳氹大橋。澳門靠左行車。
- **的士載客**：到黃色標記接客，跟着藍色導航線送到綠色標記。車資按澳門 2024 年起的收費計：首 1.6 公里 MOP 21，之後每 220 米 MOP 2。
- **跨海計時賽**：新葡京出發，經嘉樂庇總督大橋到氹仔，再經友誼大橋回來。
- **地標打卡**：走近 25 個地標自動打卡，每處 MOP 100。

金錢、打卡進度和最佳時間保存在瀏覽器本機。

## 數據來源

- 建築輪廓、樓高、道路、海岸線、公園和湖泊：© [OpenStreetMap 貢獻者](https://www.openstreetmap.org/copyright)，以 ODbL 授權。
- 部分度假村高度：維基百科「澳門最高建築列表」。
- 重點建築（新葡京、旅遊塔、大三巴、巴黎鐵塔、摩珀斯等）按公開尺寸另行建模；山體高度為推算值。
- 3D 引擎：[three.js](https://threejs.org/) r128（MIT 授權，見 `vendor/LICENSE-three.txt`）。
