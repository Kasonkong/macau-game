# 濠江飛馳 · Macau Open World

在按真實比例重建的澳門玩任務：跟住陳伯嘅故事走遍半島、氹仔同路環，揸電單車送外賣、開的士、跑東望洋賽道，沿途收集葡撻、打卡地標。

**▶ 點開即玩：<https://kasonkong.github.io/macau-game/>**

另有一個可以慢慢欣賞城市的 [澳門立體沙盤](https://kasonkong.github.io/macau-game/sandbox.html)，點選任何建築可查看名稱、地址和高度。

## 玩法

| 類別 | 內容 |
| --- | --- |
| 主線（10 個） | 由議事亭前地到澳門國際機場，一個接一個解鎖：送手信、跟蹤的士、過海、格蘭披治之夜、路氹夜遊、葡撻快遞…… |
| 支線（8 個） | 大利來記豬扒包外賣、義順雙皮奶上東望洋燈塔、黑沙海灘日落相、疊石塘山頂、營地街市掃街等 |
| 競速（5 條） | 東望洋環迴賽、澳氹雙橋、金光大道衝刺、路環環山、新城 A 區，會記錄最佳時間 |
| 打工（4 份） | 的士（按現行車資計）、外賣（由真實食肆送去真實住宅大廈）、送貨、導遊；每份完成 5 單有獎金 |
| 收集 | 40 個葡撻、25 個地標打卡 |
| 完成度 | 以上全部按比重計成一個百分比，喺暫停選單或手機「統計」睇 |

- **位置面板**：左上角顯示而家喺邊個堂區、邊條街（來自 OSM 行政區同街道名）。
- **手機（`T`）**：任務、地圖、打工、輕軌、電台、相機、統計、角色、設定。
- **大地圖（`M`）**：點擊設定導航；點已打卡的地標可以搭的士快速前往。
- **輕軌**：去車站入口（綠色柱）按互動，按真實站數收費 MOP 6–12。
- **真實商舖**：約 1,600 間 OSM 登記的商舖掛喺佢真實所在大廈臨街嗰面；走近按互動可以入去——便利店、茶餐廳、餅店買嘢食回復體力，服裝店換衫，酒店休息到第二朝。
- **住宅大廈**：約 5,500 塊大廈名牌（例如「華僑大廈」）掛喺大廈地面入口，住宅立面有鐵窗花同冷氣機，地舖有鐵閘同招牌。
- **交通**：澳門靠左行，車流會喺真實位置嘅交通燈前停車，行人喺行人路上行，巴士站有真實站名。
- 時間會由日到夜循環，天氣會轉（晴、多雲、落雨）。金錢同進度保存在瀏覽器本機。

## 操作方式

設定入面可以切換兩種操作方式，選擇會自動記住。電腦預設是鍵盤，手機和平板預設是屏幕按鈕。

| 動作 | 鍵盤 | 屏幕按鈕 |
| --- | --- | --- |
| 走路／駕駛 | `W` `A` `S` `D` 或方向鍵 | 左下搖桿 |
| 衝刺（消耗體力） | `Shift` | 「衝刺」或搖桿推到盡 |
| 跳／手掣漂移 | 空白鍵 | 「跳／手掣」 |
| 上車／落車 | `F` | 「上車／落車」 |
| 互動（任務、商舖、輕軌、對話） | `E` | 「互動」 |
| 手機 | `T` | 「手機」 |
| 大地圖 | `M` | 「地圖」或點小地圖 |
| 轉電台 | `Q` | 「電台」 |
| 響號 | `H` | 「響號」 |
| 鏡頭距離 | `V` | 「鏡頭」 |
| 相機模式／影相 | `P` | 「影相」 |
| 重置車輛 | `R` | 暫停選單 |
| 暫停 | `Esc` | ☰ |

遊戲冇武器同打鬥，玩法集中喺駕駛、送遞、競速同探索。

## 數據來源

- 建築輪廓、樓高、道路、海岸線、公園、湖泊、商舖、大廈名稱、街道名、堂區界線、交通燈、巴士站、輕軌路線同車站：© [OpenStreetMap 貢獻者](https://www.openstreetmap.org/copyright)，以 ODbL 授權。
- 部分度假村高度、山頂高度：維基百科。
- 輕軌車資分段同的士收費：按公開收費表簡化。
- 重點建築（新葡京、旅遊塔、大三巴、東望洋燈塔、巴黎鐵塔、摩珀斯、新濠影匯、科學館等）按公開尺寸另行建模；其餘山體高度為推算值。
- 3D 引擎：[three.js](https://threejs.org/) r128（MIT 授權，見 `vendor/LICENSE-three.txt`）。

## 檔案

```
index.html          遊戲
js/core.js          地形、道路、建築（臨街舖面）、地標、碰撞、路網
js/props.js         招牌同名牌、交通燈、巴士站、路燈、輕軌、葡撻、日夜天氣
js/actors.js        角色、車輛、車流、行人
js/missions.js      主線、支線、競速、打工、收集
js/audio.js         引擎聲、音效、三個電台
js/ui.js            HUD、手機、地圖、商舖、設定
js/main.js          啟動、操作、物理、鏡頭
macau-data.json     城市模型數據
macau-world.json    商舖、名牌、街道、堂區、輕軌、任務地點
sandbox.html        立體沙盤
vendor/             three.js
```

全部是靜態檔案，用 GitHub Pages（Settings → Pages → Deploy from a branch → `main` / root）即可上線。
