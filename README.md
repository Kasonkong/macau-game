# 濠江飛馳 · Macau Open World

在按真實比例重建的澳門玩任務：跟住陳伯嘅故事走遍半島、氹仔同路環，揸電單車送外賣、開的士、跑東望洋賽道，沿途收集葡撻、打卡地標。

**▶ 點開即玩：<https://kasonkong.github.io/macau-game/>**

另有一個可以慢慢欣賞城市的 [澳門立體沙盤](https://kasonkong.github.io/macau-game/sandbox.html)，點選任何建築可查看名稱、地址和高度。

## 玩法

| 類別 | 內容 |
| --- | --- |
| 主線（10 個） | 由議事亭前地到澳門國際機場，一個接一個解鎖：送手信、跟蹤的士、過海、格蘭披治之夜、路氹夜遊、葡撻快遞…… |
| 支線（13 個） | 大利來記豬扒包外賣、義順雙皮奶上東望洋燈塔、黑沙海灘日落相、疊石塘山頂、營地街市掃街、大炮台影相、三盞燈外賣、主教山祈福、龍環葡韻婚紗相、譚公廟送貨等 |
| 競速（5 條） | 東望洋環迴賽、澳氹雙橋、金光大道衝刺、路環環山、新城 A 區；同 3 個 AI 對手鬥快，要攞第一先算贏，會記錄最佳時間 |
| 打工（4 份） | 的士（按現行車資計）、外賣（由真實食肆送去真實住宅大廈）、送貨、導遊；每份完成 5 單有獎金 |
| 收集 | 40 個葡撻、25 個地標打卡 |
| 完成度 | 以上全部按比重計成一個百分比，喺暫停選單或手機「統計」睇 |

- **位置面板**：左上角顯示而家喺邊個堂區、邊條街（來自 OSM 行政區同街道名）。
- **手機（`T`）**：任務、地圖、打工、輕軌、電台、相機、統計、角色、設定。
- **大地圖（`M`）**：點擊設定導航；點已打卡的地標可以搭的士快速前往。
- **輕軌**：去車站入口（綠色柱）按互動，按真實站數收費 MOP 6–12。
- **真實商舖**：約 1,600 間 OSM 登記的商舖掛喺佢真實所在大廈臨街嗰面；走近按互動可以入去——便利店、茶餐廳、餅店買嘢食回復體力，服裝店換衫，酒店休息到第二朝。
- **住宅大廈**：約 5,500 塊大廈名牌（例如「華僑大廈」）掛喺大廈地面入口，住宅立面有鐵窗花同冷氣機，地舖有鐵閘同招牌。
- **交通**：澳門靠左行，車流會喺真實位置嘅交通燈前停車，行人喺行人路上行，巴士站有真實站名。
- **車房**：用任務同打工賺返嚟嘅錢買車（電單車、房車、客貨車、黑色的士、跑車），揀顏色、改裝引擎，隨時喺手機叫車到身邊。跑車街上搵唔到，只可以喺車房買。
- **交通違例**：衝紅燈或者經過測速相機超速會被罰款，連續 5 公里冇違例有成就；競速期間唔計，設定入面可以關閉。
- **成就**：20 個成就（例如跨海王者、葡撻大師、老司機、夜貓），每個獎勵 MOP 200。
- **畫面**：有日落同星空嘅天空、夜晚路燈光暈、會反光嘅海面。
- **街景細節**：夜晚全城車輛著車頭燈同尾燈、的士頂燈同巴士路牌會發光；剎車有剎車燈，漂移會留低胎痕；落雨時行人會擔遮，大雨會行雷閃電；外港碼頭同氹仔碼頭有噴射船開出，機場有飛機升降。
- **舖頭營業時間**：大部分舖頭夜晚 11 點後落閘，聽朝 8 點再開；便利店同酒店 24 小時，餐廳開到凌晨 2 點。
- **街坊反應**：揸車擦過行人、響號或者撞到人，佢哋會開口講嘢；仲有城市環境聲、腳步聲同雀仔叫。
- **任務角色**：附近可以接嘅任務，標記旁邊會企住任務人物（例如陳伯）同名牌，走近會向你揮手。
- **地標夜景**：夜晚新葡京、旅遊塔、新濠影匯、摩珀斯同大笨鐘會亮燈，高樓頂有閃紅色航空燈。
- **導航**：修正咗路網斷開嘅問題（OSM 街道喺交叉口中間相連），而家全澳導航同 AI 都可以搵到路。
- **駕駛手感**：車速越快視野越闊，撞車時鏡頭會震；撞車唔再即刻扣錢，改為車身損壞——損壞超過 60% 會冒煙、超過 50% 開始變慢，可以揸去真實維修舖或車行（地圖「修」字）按互動維修。
- **GPS 指示**：設咗導航之後，左下角會顯示「120 米後右轉 · 入 新馬路」咁嘅轉彎提示。
- **其他車響號**：你停喺車前面阻住佢，等耐咗佢會響你。
- **效能**：遠處建築自動隱藏，太卡時會自動降低解像度（設定入面可以關閉同顯示 FPS）。
- 時間會由日到夜循環，天氣會轉（晴、多雲、落雨）。金錢同進度保存在瀏覽器本機。

## 操作方式

設定入面可以切換兩種操作方式，選擇會自動記住。電腦預設是鍵盤，手機和平板預設是屏幕按鈕。

| 動作 | 鍵盤 | 屏幕按鈕 |
| --- | --- | --- |
| 走路／駕駛 | `W` `A` `S` `D` 或方向鍵 | 左下搖桿 |
| 衝刺（消耗體力） | `Shift` | 「衝刺」或搖桿推到盡 |
| 跳／手掣漂移 | 空白鍵 | 「跳／手掣」 |
| 上車／落車 | `F` | 「上車／落車」 |
| 互動（任務、商舖、輕軌、對話） | `E` | 「互動」 |
| 手機 | `T` | 「手機」 |
| 大地圖 | `M` | 「地圖」或點小地圖 |
| 轉電台 | `Q` | 「電台」 |
| 響號 | `H` | 「響號」 |
| 鏡頭距離 | `V` | 「鏡頭」 |
| 相機模式／影相 | `P` | 「影相」 |
| 重置車輛 | `R` | 暫停選單 |
| 轉鏡頭 | 直接郁滑鼠（點一下畫面鎖定滑鼠；設定可改做按住左鍵拖動） | 拖動畫面 |
| 暫停 | `Esc`（同時放開滑鼠） | ☰ |

另外支援遊戲手掣（Xbox／PlayStation）：左搖桿行路、右搖桿轉鏡頭、RT／LT 油門同剎車、X 上落車、Y 互動、A 跳／手掣、十字鍵上開手機；手機同選單入面用十字鍵揀、A 確定、B 返回。

遊戲冇武器同打鬥，玩法集中喺駕駛、送遞、競速同探索。

- 重點建築（新葡京、旅遊塔、大三巴、東望洋燈塔、巴黎鐵塔、摩珀斯、新濠影匯、科學館等）按公開尺寸另行建模；其餘山體高度為推算值。

## 檔案

```
index.html          遊戲
js/core.js          地形、道路、建築（臨街舖面）、地標、碰撞、路網
js/props.js         招牌同名牌、交通燈、巴士站、路燈、輕軌、葡撻、日夜天氣
js/actors.js        角色、車輛、車流、行人
js/missions.js      主線、支線、競速、打工、收集
js/audio.js         引擎聲、音效、三個電台
js/ui.js            HUD、手機、地圖、商舖、設定
js/extras.js        車房、交通違例、成就、天空、手掣、效能
js/life.js          車燈、胎痕、擔遮、閃電、渡輪、飛機、營業時間、街坊對白、環境聲
js/main.js          啟動、操作、物理、鏡頭
macau-data.json     城市模型數據
macau-world.json    商舖、名牌、街道、堂區、輕軌、任務地點
sandbox.html        立體沙盤
vendor/             three.js
```

全部是靜態檔案，用 GitHub Pages（Settings → Pages → Deploy from a branch → `main` / root）即可上線。
